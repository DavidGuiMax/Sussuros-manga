# Sussuros Mangá

Plataforma web focada em leitura de mangás e ajudar criadores de mangás com dicas.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Git/GitHub

## Funcionalidades
- Dica Para Criadores
- Biblioteca
- Layout responsivo
- Navegação dinâmica
